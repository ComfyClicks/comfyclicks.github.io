BarterAid

Understand value beyond dollars.

BarterAid is a live cross-asset value platform that translates current cryptocurrency and metals prices into comparisons people can understand. Instead of stopping at a dollar quote, it shows what one asset buys in another, what familiar expenses represent across markets, and how asset values relate to income.

The idea

Why I built it

Most market tools answer one question: “What is this asset worth in dollars?” I created BarterAid to explore a more useful second question: “What does that value mean?”

By placing metals and cryptocurrencies into one comparison system, BarterAid turns abstract prices into relative value and familiar purchasing-power context. Users can compare assets directly, express everyday expenses in different forms of value, and translate asset prices into concepts such as purchasing power and time spent earning them.

The product

What users can do

One shared value model supports a set of connected ways to understand and use live prices.

  • Compare live asset prices, daily changes, market status, and relative value.

  • Convert custom amounts between assets and units.

  • Explore purchasing-power benchmarks, asset ratios, rankings, and time-to-earn estimates.

  • Build a browser-persisted portfolio and track its combined live value.

  • Explore dedicated asset experiences with pricing, cross-asset equivalents, and purchasing-power context.

Shared pricing model

Market-data APIs return different formats and operate under different market conditions. I normalize their responses into a shared pricing model used across conversions, ratios, purchasing-power experiences, asset pages, and portfolio calculations.

Resilient by default

The application uses market-aware caching, coordinated refreshes, data validation, and layered recovery to remain useful when external data is incomplete or temporarily unavailable. Previously validated values can be preserved rather than allowing partial upstream responses to degrade the application.

Market-aware behavior

Building BarterAid required deciding not only how each feature should work, but how the application should behave when external data is incomplete, caches expire, market sessions change, or supporting infrastructure becomes temporarily unavailable.

Operational quality

Built for production

BarterAid is a live, actively maintained production application, with reliability, security, performance, testing, and monitoring considered throughout its development and operation.

Security
Administrative and scheduled operations use layered protections including authenticated sessions, request validation, abuse controls, and restrictive browser security policies.
Observability
An authenticated operations dashboard provides visibility into data-source health, cache behavior, scheduled processing, telemetry, and operational events.
Performance
Server-rendered initial data, shared client state, caching, deferred work, and coordinated refreshes reduce unnecessary network and computation costs.
Accessibility
Semantic structure, keyboard-accessible controls, visible focus states, screen-reader support, reduced-motion handling, and responsive layouts are incorporated throughout the interface.
Testing
A comprehensive automated test suite covers pricing and recovery behavior, caching, authentication, telemetry, feature gating, persisted state, and public application behavior.
